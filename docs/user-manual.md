# 포도뱅크 사용자 매뉴얼

이 매뉴얼은 프론트엔드와 로컬 목 API 서버로 포도뱅크 화면을 시연하는 방법을 안내합니다. 표시되는 계좌, 거래, 카드, 대출은 모두 가상 데이터입니다.

## 1. 실행하기

`frontend` 폴더에서 터미널 두 개를 열고 각각 실행합니다.

```powershell
npm run mock:api
```

```powershell
npm run dev:mock
```

개발 서버가 출력하는 주소(기본값 `http://localhost:5173/`)를 브라우저에서 엽니다. 목 API 서버 주소는 `http://127.0.0.1:8001`입니다.

목 서버는 별도의 데이터베이스를 사용하지 않습니다. 계좌 잔액, 거래, 대출 신청은 메모리에만 저장되고 목 API 서버를 다시 시작하면 초기 데이터로 돌아갑니다.

## 2. 시연 계정으로 로그인하기

- 전화번호: `01000000000`
- 비밀번호: 비어 있지 않은 임의의 값

목 API 서버에서만 동작하는 시연 계정입니다.

![로그인 화면](images/user-manual/02-login.png)

## 3. 홈과 계좌 확인하기

로그인하면 홈에서 계좌 잔액, 자산 요약, 최근 거래를 확인할 수 있습니다. 하단 메뉴의 **계좌**를 누르면 계좌번호와 거래 내역을 볼 수 있고, 입금·출금·송금 화면으로 이동할 수 있습니다.

![로그인 후 홈](images/user-manual/03-home.png)

![계좌와 거래 내역](images/user-manual/04-accounts.png)

입금 또는 출금 화면에서 금액을 입력하고 아래 버튼을 누릅니다. 금액 빠른 입력 버튼도 사용할 수 있습니다.

![입금 금액 입력](images/user-manual/05-deposit.png)

## 4. 송금하기

송금 화면에서 받는 분 전화번호 `01000000001` 또는 계좌번호 `200-1234-0001`을 입력합니다. 이름이 확인되면 금액을 입력하고 **보내기**를 누릅니다. 시연용 수취인은 `이하늘`입니다.

![받는 분과 금액 확인](images/user-manual/06-transfer-ready.png)

완료 화면에서 보낸 금액과 남은 잔액을 확인할 수 있습니다.

![송금 완료](images/user-manual/07-transfer-result.png)

## 5. 체크카드 결제하기

하단 메뉴의 **카드**에서 가맹점을 고르고 결제 금액을 입력한 뒤 결제 버튼을 누릅니다. 결제 금액은 목 계좌 잔액과 거래 내역에 반영됩니다.

![카드와 가맹점 선택](images/user-manual/08-card.png)

![결제 금액 입력](images/user-manual/08-card-amount.png)

![카드 결제 완료](images/user-manual/09-card-paid.png)

## 6. 대출 신청하기

하단 메뉴의 **대출**에서 상품, 금액, 기간을 선택하고 신청합니다. 목 서버는 신청 상태를 **심사 대기**로 저장합니다.

![대출 신청 입력](images/user-manual/10-loan-application.png)

![대출 심사 대기](images/user-manual/11-loan-pending.png)

## 목 API 범위

- 시연 계정 로그인과 로그아웃
- 계좌 잔액과 거래 내역 조회
- 입금, 출금, 수취인 조회, 송금
- 체크카드 및 가맹점 조회, 결제
- 대출 상품 조회, 신청 및 심사 대기 상태 조회
- 목 데이터는 서버 프로세스 메모리에만 존재하며 재시작 시 초기화

외부 금융 서비스, 실제 계좌, 실제 송금은 연결되어 있지 않습니다.
